# 两个 agent 的任务工作流

用两个 agent 来完成输入的任务。

Players:

- `编码者`
- `审查者`

`编码者` 是按任务要求对当前目录的代码进行修改并提交的 agent；`审查者` 是对提交的
commit 进行 review 的 agent。

## 步骤

1. 开始工作前，确保当前目录本身是一个 Git 仓库的根目录；若此处没有 `.git`，就在此处
   初始化一个 Git 仓库。

2. `编码者` 按任务要求对当前目录的代码进行修改并提交 Git。

3. `审查者` 对提交的 commit 进行 review 并提出合理问题，交回给 `编码者` 做判断。

4. `编码者` 做判断：可以接受或拒绝，但要讲清楚原因。

5. `编码者` 与 `审查者` 争论直至达成一致（争论不超过 2 轮，即至多到总计第 3 次判断后
   不再争论）。

6. `编码者` 负责按结论修改代码，再次提交。

7. 依此循环（第 2–6 步），直到 review 没有任何问题后结束。循环次数不超过 2 次。
