Roles:

- `编码者`
- `审查者`

## 流程

1. 开始工作前，确保当前目录本身是一个 Git 仓库的根目录；若此处没有 `.git`，就在此处初始化一个 Git 仓库。

2. 用两个agent来完成输入的任务：一个agent为 `编码者`，另一个agent为 `审查者`。

3. `编码者` 按任务要求对当前目录的代码进行修改并提交Git。

4. `审查者` 对提交的commit进行review并提出合理问题，交回给 `编码者` 做判断。

5. `编码者` 可以接受或拒绝但要讲清楚原因。

6. 两个agent争论直至达成一致（争论不超过2轮，即至多到总计第3次判断后不再争论）。

7. 由 `编码者` 负责按结论修改代码，再次提交。

8. 依此循环，直到review没有任何问题后结束。循环次数不超过2次。
